# Регистры и инварианты Pass26

## Живое состояние регистров

| Регистр | Использование | Когда переиспользуется |
|---|---|---|
| `r1` | нулевой регистр после startup | не должен стать не-нулём перед использующими его инструкциями |
| `r2` | источник USB-ответа: Flash/SRAM/EEPROM | для READ8/передачи, см. bit0 и bit7 |
| `r3` | отложенная Flash/SPM операция | после завершения контрольного обмена |
| `r4:r5` | постоянный **байтовый** указатель Flash/EEPROM (r5.7 — EEPROM) | пользовательские SELECT, READ8 +8, WRITE4 +4 |
| `r6:r7` | интервал ожидания/idle | не должен разрушаться низкоуровневым USB PHY |
| `r8` | число оставшихся EEPROM байтов в очереди | EEPROM background writer |
| `r10–r13` | 4 байта очереди записи EEPROM | только пока активна операция |
| `r23` | длина RX внутри PHY | после приёма RX мёртв, переинициализируется TX/CRC |
| X=`r26:r27` | счётчик USB опроса вне PHY, указатель буфера USB TX внутри | НЕ постоянный указатель пользовательской памяти |
| Y=`r28:r29` | контекст USB в основном обработчике, RX/TX внутри PHY | перезагрузка в нужных местах обязательна |
| Z=`r30:r31` | временный Flash/SPM/USB-адрес | часто используется `LPM`/`SPM`/`LD Z+` |

См. полноту живости регистров в комментариях исходного `micronucleus_t88_pass26.S`.
Пара X/Y/Z не закреплена глобально: V-USB её уже использует. Убирать загрузки
указателей можно только при доказанной живости и отсутствии промежуточного
обработчика, который меняет пару.

## Инварианты памяти

- ATtiny88: Flash 8192 байта, EEPROM 64 байта, размер страницы Flash 64 байта.
- SELECT `wIndex`: бит15 выбирает EEPROM, остальные 15 бит — номер блока 4 Б.
- Внутри программы `r4:r5` хранит *байтовый* адрес; перевод `block * 4`
  делается **только при SELECT**, не при каждом READ8/WRITE4.
- READ8 потребляет/сдвигает ровно 8 байт; WRITE4 — ровно 4. При ошибках
  хост обязан забыть курсор, проверить результат и повторно выбрать адрес.
- EEPROM READ8 во время занятой EEPROM может возвращать короткий/пустой
  результат, и указатель в этом случае не должен продвигаться.
- SELECT+ERASE применяется только к Flash со страницей, выровненной по 64 Б;
  граница загрузчика должна проверяться **на ATtiny88** перед `SPM`.
- APP_END=`BOOT_AT-4` (postscript 4 Б); RESET приложения готовится хостом.
- Для сборок без LED `BOOT_AT=0x1B40`; для LED `0x1B00`. См. manifest.
- Релизные USB дескрипторы bcdDevice `0x0550..0x0552` различают компоновку.

## Тайминги

- 16 МГц означает примерно 10.6667 такта на бит USB Low-Speed (1.5 Мбит/с).
  Простое числовое равенство числа инструкций НЕ означает равенства фаз на шине.
- Pass25 убирает сохранение/восстановление X/Y и сдвигает ранний старт RX на 4
  такта; поздние входы (примерно фазы 16–19, 37–40 модели) отличаются.
- Pass26 переносит RX-счётчик `r19→r23` с двухтактной паузой вместо PUSH:
  внутри битовых циклов фазы сохранены, после завершения RX возврат короче.
- Две `ADIW/SBIW` замены проверены для всех 256/65536 адресов и необходимых
  флагов. Эти тесты не являются измерением аналогового USB-сигнала.

## Точки аудита

- `audit_phy26.py`: допустимые опкоды, числа инструкций, переходы.
- `tests26/test26_phy_arithmetic.py`: все адреса и флаги для замен.
- `tests26/test26_cursor_opcodes.py`: исполняемая модель переходов указателя.
- `tests26/test26_nvm.py`: реальная последовательность инструкций записи.
- `tests26/test26_host_stream.py`: состояние хостового курсора и ошибки.
