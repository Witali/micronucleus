# Краткая техническая история компактной ветки ATtiny88

Этот документ — конспект разработки, не полный экспорт переписки и не
достоверная история коммитов GitHub. Часть промежуточных Pass сохранена в
предыдущих локальных архивах, **не входящих в данный handoff**.

| Шаг | Размер без LED | Основная идея |
|---|---:|---|
| Strict USB optimized | 1262 Б | Стабильные оптимизированные USB+Flash/EEPROM, протокол до v5.x; предшественник 1274 Б был проверен на плате |
| Pass16 | 1260 Б | Перестановка обработчиков EEPROM/Flash для сокращения RJMP |
| Pass19 | 1326 Б | Единое чтение 8 Б и запись EEPROM по 4 Б; расширенная функциональность |
| Pass21 | 1270 Б | Бит 15 = тип памяти, блоковый адрес и перенос RESET-патча на ПК |
| Pass22 | 1270 Б | Возможность читать загрузчик и определять сборку; затем от отпечатков отказались |
| Pass23 | 1240 Б | Удаление дублирующихся проверок чтения; единый bcdDevice для различения профилей |
| Pass24 | 1224 Б | Общий SELECT+ERASE, упрощение ветвей и инициализации |
| Pass25 | 1216 Б | Первая 19-страничная компоновка; PHY 498 Б, риски сдвига фазы RX |
| **Pass26** | **1206 Б** | Регистр `r4:r5` = общий курсор, RX `r23`, `ADIW/SBIW`; PHY 492 Б |

Совместимость **старых приватных протоколов** намеренно не сохраняется.
Последний собственный протокол: **v5.5**, пять команд SELECT (1),
SELECT+ERASE (2), WRITE4 (3), RUN (4), READ8 (0xB0).

Не путать с `experimental/attiny88/block64` в пользовательском GitHub-форке:
это другая экспериментальная ветка с иным форматом USB-операций и более
сложной стадийностью ACK/CRC. Pass26 — **strict USB compact**.

Старые готовые образы Pass25 и отдельные Pass22/24 исходники сохранены
в `variants/strict_usb_optimized/` для побайтного/опкодного сравнения.
Проверка CRC и физической совместимости USB никогда не должна считаться
закрытой лишь на основании их прежних исторических тестов.
