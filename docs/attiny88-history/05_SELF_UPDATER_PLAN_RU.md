# Проект Self-Updater для ATtiny88 — пока только план

Запрос: позволить одной MH-Tiny88 с имеющимся Micronucleus обновлять собственный загрузчик через USB, без внешнего ISP, загружая временную прошивку в пользовательскую Flash. Оригинальный проект Micronucleus содержит upstream файл `firmware/upgrade.c` для ATtiny85 — см. `05_REFERENCE_LINKS/UPSTREAM.md`.

## Возможная последовательность

1. На ПК построить **специальный HEX приложения**, содержащий updater + полный бинарный образ загрузчика + длину и контрольную сумму. Проверить, что всё помещается в доступную пользовательскую Flash, в т.ч. `0x1ABC..0x1ABF` постскрипт.
2. Записать HEX через **существующий исправный** Micronucleus USB, запустить. Область до `0x1AC0` должна содержать весь updater; она не должна стираться в ходе обновления загрузчика.
3. Updater отключает V-USB/прерывания и подтверждает checksum встроенного образа и страницу назначения; при несовпадении — НЕ начинать запись.
4. До стирания загрузчика спроектировать сброс-вектор на updater так, чтобы неожиданный сброс не запускал наполовину переписанный загрузчик. Изменение первой страницы — само по себе потенциально опасная операция, поэтому сначала проверить на эмуляторе и физически с ISP-доступом.
5. Пройти каждую 64-байтовую страницу: выровнять адрес, очистить Page Buffer, выполнить `SPM` erase/fill/write, дождаться готовности (правильная обработка RWWSB и других состояний из официального datasheet), проверить через `LPM`.
6. Проверить CRC/байтовое совпадение всего нового загрузчика, включая вектора и позицию `0x1AC0`.
7. В самом конце изменить вектор RESET, проверить его и перезапустить/запустить новый загрузчик.
8. Обработать неудачу записи. **Без второго Flash банка, внешнего энергонезависимого накопителя или аппаратной защиты полного восстановления от сбоя питания гарантировать нельзя.** Оставить инструкции ISP-восстановления.

## Особые проверки для ATtiny88

- Биты Fuse (SELFPRGEN, CKSEL/CKDIV8, WDT/BOD), напряжение, физическая частота 16 МГц.
- Программирование через SPM **из приложения**, а не из аппаратной отдельной секции Boot; наличие разрешения и ограничения страницы именно для ATtiny88.
- Первоначальный RESET вектор Micronucleus изменён хостом; убедиться в корректной цепочке reset->updater->новый Micronucleus.
- Смена местоположения загружчика (0x1A40, 0x1AC0 и т.д.) и старый постскрипт: не копировать буквально код upgrader для ATtiny85.
- Изменение Flash в момент исполнения и сброс питания: делать fault-injection со внешним ISP recovery.
- Нужен отдельный законченный ASM-проект updater, generator HEX и тесты (пока нет).

## Границы выполненной работы

В предыдущей беседе Updater **обсуждён, но готовые исходники/HEX для ATtiny88 не создавались**. В данном архиве нет проверенного self-updater. Нельзя считать upstream upgrade.c для ATtiny85 готовой прошивкой ATtiny88.
