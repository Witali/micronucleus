# Add the conservative 1328-byte USB variant

Alternative for initial hardware trials: retain the original 516-byte V-USB handler and 44-byte CRC while keeping the same application capacity and memory commands as fast Pass7.

Imported from `Micronucleus_Tiny88_Fast_1320B_Pass7_2026-10-25.zip` (October 25, 2026). This is an English summary of the historical stage; the unmodified original reports and all intermediate files are preserved in `docs/attiny88-history/original-handoff.zip`.

Recorded bootloader body: **1328 bytes**; boot address: **0x1AC0**. All images are experimental. Software tests do not establish electrical USB compatibility. No hardware flashing is part of this import.
