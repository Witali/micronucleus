## Share the SETUP-shadow return

Place the context restore immediately after the six accepted SETUP shadow
loads, removing their two-byte jump. An exhausted ACK wait reaches the same
restore through the existing handshake discriminator. It cannot own an
uncaptured SETUP marker while a transmitted DATA reply awaits ACK.

## Set the EOP recovery bit directly

Replace the final ORI/OUT pair with SBI PORTD,D- and retain the existing
two-clock alignment jump. Classic-AVR SBI takes two clocks and preserves
SREG; see the [Microchip instruction manual, SBI](https://www.microchip.com/content/dam/mchp/documents/MCU08/ProductDocuments/ReferenceManuals/AVR-InstructionSet-Manual-DS40002198.pdf).
Two alignment clocks, seventeen countdown clocks and the two-clock write
still produce exactly 21 clocks of driven SE0, followed by 11 clocks of
driven J. R16 is dead after EOP; all unrelated PORTD bits are preserved.

Together with the preceding return change, the default body is **1784 bytes
at 0x1900**, SHA256
`674382805d2592c735979f8e0dbba90c0c1c0e5434cc8746b90b02fdeb61ce45`.
The independent bus-event EOP gate passes 975 DATA/handshake/DDR cases.
A separate 203-case comparison preserves GPIO transition times, final
context/memory/flags and external pin masks. An additional 144-case quiet
ACK-timeout followup comparison preserves eligibility expiry at J+181 clocks;
the later return does not admit an unacknowledged WRITE4 or lose a following
IN/SETUP transaction.

Transaction fixtures now observe OUT, SBI and CBI writes to PORTD. Their
existing level, timestamp, count, CRC, ownership and caller-state assertions
remain in place. This accepts the changed instruction while continuing to
check the physical GPIO operation. The known receive failures remain open.

The 1784-byte image also passed fifteen selected groups, including 1485

## Replace three ACK middle cells with one loop

Mask FIRST before decoding, then copy raw SECOND into the previous-line
register. A cold FIRST-SE0 continuation checks SECOND and decodes a recovered
transition as zero. Its instructions occupy exactly the normal decode/MOV
slots; it still rejects a zero pair. Share its final rejection jump with the
other cold branches. This removes 30 bytes without removing the early EOP
guard, changing the dense terminal polls or weakening PID/ownership checks.

## Replace the redundant receive countdown with the buffer pointer

The combined receiver already computes packet length from Y at EOF. Its R23
countdown only selects the eleventh byte's terminal continuation. Before
bit6, ten bytes have been committed exactly when Y equals RX_BUFFER+10.
Replace each of the three countdown decrements with this pointer comparison.
The following branches use Z; the differing carry is overwritten before the
next payload ROR and cannot change decoding or fractional scheduling.

Initialize R21 in the pre-PID NOP slot. The old adjacent R21/R23 initializers
then become one two-clock jump. This saves two bytes while preserving every
input observation, including the independent ACK reader's entry. That reader
still sets its own one-byte count at bit7; EOF computes the normal count.
