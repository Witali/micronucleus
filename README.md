# Micronucleus+ ATtiny88 — Pass26: independent agent handoff

**Дата состояния: 27 октября 2026 года.** Полный пакет исходников, прошивок,
хостового программатора, сравнительных версий и программных тестов.
Основная точка входа: **`AGENT_START_HERE_RU.md`**.

Это экспериментальная линейка **компактного Micronucleus+**, а **не Block64**.
Рабочая версия `Pass26`, протокол `v5.5`, аппаратно **не проверена**.
Устройство: ATtiny88, 16 МГц, V-USB Low-Speed (EP0).

| Конфигурация | Код | USB PHY | BOOT_AT | Приложение | bcdDevice |
|---|---:|---:|---:|---:|---|
| без LED | **1206 байт** | 492 байта | `0x1B40` | 6972 байта | `0x0550` |
| LED active-high | **1220 байт** | 492 байта | `0x1B00` | 6908 байт | `0x0551` |
| LED active-low | **1218 байт** | 492 байта | `0x1B00` | 6908 байт | `0x0552` |

**Воспроизведение:** `sh verify.sh`. Нужны `clang` с AVR backend,
`llvm-objdump`, `llvm-objcopy`, Python 3. Изменения на USB-устройство
или в GitHub скрипт не отправляет.

Артефакты выпуска находятся в `firmware/`; это образы **для установки на
чистую плату через внешний ISP**, а не бинарники обычного приложения для
существующего Micronucleus. Установить на единственную плату без ISP
восстановления **не следует**.

Цель следующего этапа — попытаться ужать код до 1024 байт без потери USB
контрактов. Компиляция текущего источника при `BOOT_AT=0x1C00` даёт 1202
байта (на 178 больше допустимых 1024). Пока это только исследовательская цель.

Важные каталоги: `variants/` — ASM, `host/` — Python клиент, `tests26/` —
фактические регрессии, `tests25/` — используемые предыдущие модели, `firmware/`
— контрольные собранные тела/HEX, `docs/` — инструкции для следующего агента.
